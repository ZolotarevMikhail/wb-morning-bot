# Утренняя сводка WB — Telegram-бот

Учебный проект этапа 1 (Way): бот присылает в Telegram сводку по кабинету
Wildberries — продажи, заказы, остатки. Первый кирпич будущего
«Финансового стража» (этап 2).

## Что уже работает (шаги 1–3)
- `/start` — приветствие + подписка на утреннюю сводку (10:00 МСК).
- `/stop` — отписаться от утренних сводок.
- `/summary` — сводка по кабинету WB прямо сейчас: выручка и продажи вчера
  против позавчера, новые заказы, топ товаров, заканчивающиеся остатки
  (с названиями товаров).
- Проверка без Telegram: `python3 wb_data.py` — печатает сводку в терминал.

## Как запустить

1. Установить зависимости (один раз):
   ```
   pip3 install -r requirements.txt
   ```
2. Создать бота: в Telegram написать **@BotFather** → команда `/newbot` →
   придумать имя и username. BotFather выдаст токен вида
   `1234567890:ABC...` — скопировать.
3. Рядом с ботом создать файл `.env` (можно скопировать из
   `.env.example`) и вставить токен:
   ```
   BOT_TOKEN=ваш_токен
   ```
4. Запустить:
   ```
   python3 bot.py
   ```
5. Открыть своего бота в Telegram, нажать «Старт».

Токен живёт только в `.env` — в код и в git он не попадает (см. `.gitignore`).
Если токен WB протухнет — `python3 check_wb_token.py` проверит его по всем
трём каналам и перепишет в `.env` (сам токен не печатает).

## Автоотправка
Подписка сохраняется в `subscribers.json` при команде `/start`. Поток внутри
бота сам ждёт 10:00 МСК и рассылает сводку всем подписчикам. Бот должен быть
запущен в этот момент (пока — на компьютере; для 24/7 понадобится VPS).

## Лимиты WB
API статистики WB лимитирует частоту запросов. Если бот ответит
«WB просит не спешить» — подожди минуту и повтори `/summary`. Бот делает
3 запроса за сводку: продажи за 2 дня, заказы, остатки.
