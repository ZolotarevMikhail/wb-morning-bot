# Утренняя сводка WB + Ozon — Telegram-бот

Учебный проект этапа 1 (Way): бот присылает в Telegram сводку по кабинетам
Wildberries и (опционально) Ozon — продажи, заказы, остатки. Первый кирпич
будущего «Финансового стража» (этап 2).

## Что уже работает (шаги 1–4)
- `/start` — приветствие + подписка на утреннюю сводку (10:00 МСК).
- `/stop` — отписаться от утренних сводок.
- `/summary` — сводка по WB (+ Ozon, если настроены ключи) прямо сейчас:
  выручка и продажи вчера против позавчера, новые заказы, топ товаров,
  заканчивающиеся остатки (с названиями товаров).
- `/ozon` — только Ozon-сводка: выручка и заказанные штуки, разница с
  позавчерём, заканчивающиеся товары.
- Проверка без Telegram: `python3 wb_data.py` (WB), `python3 ozon_data.py` (Ozon).

## Как запустить

1. Установить зависимости (один раз):
   ```
   pip3 install -r requirements.txt
   ```
2. Создать бота: в Telegram написать **@BotFather** → команда `/newbot` →
   придумать имя и username. BotFather выдаст токен вида
   `1234567890:ABC...` — скопировать.
3. Рядом с ботом создать файл `.env` (можно скопировать из
   `.env.example`) и вставить токен:
   ```
   BOT_TOKEN=ваш_токен
   ```
   Для сводки по Ozon добавить ещё две строки (кабинет Ozon →
   Настройки → API-ключи):
   ```
   OZON_CLIENT_ID=ваш_client_id
   OZON_API_KEY=ваш_api_key
   ```
   Режим работы задаёт строка `AUTO_SUMMARY`:
   - `AUTO_SUMMARY=0` (сейчас) — ручной режим: сводка только по команде
     `/summary` или `/ozon`;
   - `AUTO_SUMMARY=1` — вернётся утренняя рассылка в 10:00 МСК.
   После любой правки `.env` бот нужно перезапустить — он читает `.env`
   один раз при старте.
4. Запуск вручную (для отладки):
   ```
   python3 bot.py
   ```
5. Автозапуск при включении компьютера настроен через launchd
   (встроенный планировщик macOS). Файл агента:
   `~/Library/LaunchAgents/ru.zolmy.wb-bot.plist`.
   Управление вручную:
   ```
   launchctl load    ~/Library/LaunchAgents/ru.zolmy.wb-bot.plist   # включить автозапуск
   launchctl unload  ~/Library/LaunchAgents/ru.zolmy.wb-bot.plist   # выключить
   launchctl kickstart gui/$(id -u)/ru.zolmy.wb-bot                 # перезапустить бота
   ```
   Лог: `bot.log` рядом с ботом. Пока интернета/VPN нет, бот просто
   повторяет подключение к Telegram — как только сеть появится, команды
   заработают без перезапуска.
6. Открыть своего бота в Telegram, нажать «Старт».

Токен живёт только в `.env` — в код и в git он не попадает (см. `.gitignore`).
Если токен WB протухнет — `python3 check_wb_token.py` проверит его по всем
трём каналам и перепишет в `.env` (сам токен не печатает).

## Автоотправка (опционально)
Выключена строкой `AUTO_SUMMARY=0` в `.env`. Если вернуть `AUTO_SUMMARY=1`,
подписка сохраняется в `subscribers.json` при команде `/start`, и поток внутри
бота сам ждёт 10:00 МСК и рассылает сводку всем подписчикам. Бот должен быть
запущен в этот момент (пока — на компьютере; для 24/7 понадобится VPS).

## Лимиты WB
API статистики WB лимитирует частоту запросов. Если бот ответит
«WB просит не спешить» — подожди минуту и повтори `/summary`. Бот делает
4+ запроса за сводку: продажи за 2 дня, заказы, названия карточек (может
добавить страницы), остатки. Если настроен Ozon — отдельные запросы к нему.
